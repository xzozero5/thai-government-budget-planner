# Wireframes (T-401, docs/06-UI-SPEC.md §4)

ASCII wireframe ทุกหน้า + ทุก state · ข้อความจริงอยู่ใน `docs/ui/copy.th.json` (ที่นี่เขียนย่อเพื่ออ่านง่าย)
Breakpoint: `lg ≥ 1024px` (3-pane), `md 768–1023px` (2-pane ซ้อน), `sm < 768px` (แท็บสลับ)

สัญลักษณ์: `[ ปุ่ม ]` · `( ตัวเลือก )` · `▣ จากงบจริง` `◆ ราคาตลาด` `◌ ประมาณการ` · `●●●` ความมั่นใจ · `⌛` loading · `!` error
