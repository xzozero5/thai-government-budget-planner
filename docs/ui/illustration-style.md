# Illustration style guide — SVG ที่ AI สร้าง (T-401, docs/06-UI-SPEC.md §7 ข้อ 6, N9)

ใช้เป็นเนื้อหาของ `<illustration_style>` ใน system prompt ของ `emit_illustration` (docs/05-FEATURES.md §98)
ภาพทุกชิ้น **สร้างโดย Claude เท่านั้น** และ **ต้องผ่าน `sanitizeSvg()` ก่อน render ทุกครั้ง**

## 1. สรุปสไตล์ (บอก AI แบบสั้น)

> ภาพแผนผังแบบ flat 2 มิติ เส้นเดียวหนา 2px สีจาก palette ที่กำหนด พื้นขาว ไม่มีไล่เฉดสี ไม่มีเงา
> ไม่มี texture เหมือนภาพร่างวิศวกรรมที่อ่านง่ายสำหรับคนทั่วไป มีป้ายข้อความไทยกำกับองค์ประกอบสำคัญ
> และมีเส้นบอกระยะ/สัดส่วนเทียบ (คนสูง 1.70 ม.) เพื่อให้เห็นขนาดจริง

## 2. กฎที่ sanitizer บังคับ (ถ้าผิด ภาพจะถูกตัดหรือปฏิเสธ)

| กฎ | เหตุผล |
|---|---|
| root เป็น `<svg xmlns="http://www.w3.org/2000/svg">` และ **ต้องมี `viewBox="0 0 800 450"`** | บังคับโดย `sanitizeSvg` (ไม่มี viewBox = reject) |
| ขนาดไฟล์ **≤ 60 KB** (UTF-8) | reject ถ้าเกิน |
| **ห้าม** `<script> <style> <foreignObject> <use> <image> <a> <animate*> <set> <iframe> <object> <embed> <link> <meta>` | ถูกตัดทั้ง element |
| **ห้าม** attribute `style=` (inline CSS) — ใช้ presentation attribute (`fill`, `stroke`, `stroke-width`) แทน | ถูกลบทิ้งเสมอ |
| **ห้าม** `href` / `xlink:href` / `on*` ทุกชนิด | ถูกลบ |
| **ห้าม** `<!DOCTYPE>` / `<!ENTITY>` | reject ทั้งไฟล์ |
| **ห้าม backslash (`\`)** ในค่า attribute ใด ๆ | ถูกลบ attribute นั้น (กัน CSS escape) |
| `url()` ใช้ได้เฉพาะ `url(#id)` ที่อ้าง `<defs>` ในไฟล์เดียวกัน — ห้าม `://`, `//`, `image-set()`, `@import`, `data:`, `javascript:` | ถูกลบ |
| ใช้สี **จาก palette ข้อ 3 เท่านั้น** (เป็น hex ตรง ๆ) | สีนอก palette ได้ warning และภาพจะไม่กลมกลืนกับ UI |
| ฟอนต์ใช้ `font-family="sans-serif"` (ฟอนต์ระบบ) เท่านั้น | ห้ามโหลดฟอนต์ภายนอก; ใน PDF จะถูก raster เป็น PNG |

> อนุญาต: `<g> <path> <rect> <circle> <ellipse> <line> <polyline> <polygon> <text> <tspan> <defs> <title> <desc> <linearGradient>`
> — แต่ **สไตล์ของเราห้ามใช้ gradient** (06 §1 flat) ถึงแม้ sanitizer จะปล่อยผ่าน

## 3. Palette (hex ตรงกับ `web/src/styles/tokens.css` โหมด light)

| บทบาทในภาพ | hex | token ต้นทาง |
|---|---|---|
| พื้นกระดาษ (rect เต็มเฟรมชิ้นแรก **บังคับ**) | `#ffffff` | `--surface` |
| กรอบ/เส้นแบ่งจาง | `#e6e8ee` | `--border` |
| พื้นรอง / อาคาร | `#e9eaf1` | `--basis-estimate-bg` |
| เส้นหลัก โครงสร้าง ตัวอักษรหัวข้อ | `#2d2a4a` | `--primary` (น้ำเงินธงชาติ) |
| เส้นรอง ป้ายกำกับ เส้นบอกระยะ | `#5d6178` | `--text-muted` |
| ผิวคอนกรีต/เหล็ก/ถนน | `#4d5168` | `--basis-estimate` |
| น้ำ ท่อ พืชน้ำ (เส้น) | `#0f6e6e` | `--basis-historical` |
| น้ำ (พื้น) | `#dff3f1` | `--basis-historical-bg` |
| ดิน/หลังคา (เส้น) | `#8a5300` | `--basis-market` |
| ดิน/หลังคา (พื้น) | `#fdefd3` | `--basis-market-bg` |
| ต้นไม้/พืช (เส้น) | `#166b40` | `--success` |
| **จุดเน้นเดียวของภาพ** (สิ่งที่โครงการจะสร้าง/ซื้อ) | `#a51931` | `--accent` — ใช้ **< 10 %** ของพื้นที่ |
| พื้นกล่องคำอธิบาย | `#f4f5f8` | `--bg` |

- ภาพต้องวาด `<rect>` สีขาวเต็มเฟรมเป็น element แรกเสมอ เพื่อให้อ่านออกทั้ง light/dark (กรอบใน UI เป็น `bg-surface-2`)
- ห้ามใช้ `#a51931` กับเส้นทั่วไป — สงวนไว้เฉพาะองค์ประกอบที่เป็น "ของใหม่ที่จะใช้งบ"

## 4. มุมมองที่ใช้ได้ (`kind`)

| kind | ใช้เมื่อ | แนวทาง |
|---|---|---|
| `map` | บอกตำแหน่ง/บริบทพื้นที่ | มองจากบนลงล่าง, มีเข็มทิศ + แถบมาตราส่วนอย่างง่าย, ถนนเป็นเส้นหนา 16px มีเส้นประขาวกลาง, ลำน้ำเส้นหนา 22px |
| `cross_section` | สิ่งก่อสร้างที่มีความสูง/ชั้นดิน | ตัดขวางจากด้านข้าง, มีเส้นบอกระยะพร้อมหัวลูกศรทั้งสองด้าน, มีระดับน้ำ/ระดับดิน, มีคนเทียบสัดส่วน |
| `isometric` | อาคาร/ลานจอด/ผังที่ต้องเห็นมิติ | มุม 30° (`dx:dy = 1:0.577`) เส้นขนานล้วน ห้ามมี perspective จุดรวมสายตา |
| `diagram` | ระบบ/ลำดับการทำงาน (ประปา ไฟฟ้า เครือข่าย) | กล่อง + ลูกศรทิศทาง, ใส่เลขลำดับ 1..n, มีกล่องคำอธิบายสัญลักษณ์ |

## 5. องค์ประกอบมาตรฐาน (ให้ AI ลอกสัดส่วนนี้)

| องค์ประกอบ | รูปแบบ | สัดส่วนใน viewBox 800×450 |
|---|---|---|
| คน | วงกลมหัว r=9 + ลำตัว/แขน/ขา เส้น 2px | สูงรวม ~70px = 1.70 ม. (ใช้เป็นสเกลอ้างอิง) |
| บ้าน | สี่เหลี่ยม `#e9eaf1` + หลังคาสามเหลี่ยม `#fdefd3` | กว้าง 38–52px |
| อาคาร 3 ชั้น | สี่เหลี่ยม + เส้นแบ่งชั้นแนวนอน + ช่องหน้าต่างเป็น rect เล็ก | สูง 120–160px |
| ต้นไม้ | วงกลม r=12–16 เส้น `#166b40` พื้น `#dff3f1` (กลุ่มละ 2–3 วง) | – |
| ถนน | เส้น `#4d5168` หนา 16px + เส้นประขาว 2px ทับกลาง | – |
| น้ำ (ผิวบน) | เส้น `#0f6e6e` 2px + พื้น `#dff3f1` | – |
| ท่อ | เส้น `#0f6e6e` 2px + ลูกศรหัวเปิด (2 เส้นทำมุม) | หัวลูกศรยาว 10–12px |
| ดิน | พื้น `#fdefd3` เส้นขอบ `#8a5300` + เส้นประชั้นล่าง | – |
| เส้นบอกระยะ | เส้น `#5d6178` 2px + หัวลูกศร 2 ข้าง + ข้อความ "กว้าง 12.00 ม." | font-size 16 |
| ป้ายหัวข้อ | `<text>` `#2d2a4a` font-size 18–20 | – |
| ป้ายกำกับย่อย | `<text>` `#5d6178` font-size 14–16 | – |

## 6. ข้อห้ามด้านเนื้อหา

1. **ห้ามใส่ตัวเลขเงินในภาพ** (บาท/ราคา/งบ) — ตัวเลขเงินอยู่ใน BOQ ที่มี citation เท่านั้น (N3)
2. ห้ามใส่ตราสัญลักษณ์ราชการ ธงชาติ โลโก้หน่วยงาน หรือชื่อบุคคลจริง
3. ห้ามวาดให้ดูเหมือนแบบก่อสร้างที่ใช้ก่อสร้างได้จริง — caption ต้องบอกเสมอว่า "เชิงแผนผัง"
4. ตัวเลขมิติที่ใส่ในภาพต้องตรงกับสเปคในข้อเสนอ ถ้ายังไม่ยืนยันให้ใส่คำว่า "ประมาณ" นำหน้า
5. ข้อความในภาพเป็นภาษาไทย สั้น ≤ 5 คำต่อป้าย; ห้ามใส่ย่อหน้ายาว
6. องค์ประกอบทั้งภาพ ≤ 40 ชิ้น (อ่านง่าย + ไฟล์เล็ก)

## 7. ตัวอย่าง few-shot (ใช้แนบใน prompt)

| ไฟล์ | kind | สอนอะไร |
|---|---|---|
| `illustrations/01-map-weir-village.svg` | `map` | ผังพื้นที่ ถนน/ลำน้ำ/หมู่บ้าน/เข็มทิศ/มาตราส่วน + จุดเน้น accent |
| `illustrations/02-cross-section-weir.svg` | `cross_section` | ตัดขวาง ระดับน้ำ ชั้นดิน เส้นบอกระยะ คนเทียบสัดส่วน |
| `illustrations/03-diagram-water-system.svg` | `diagram` | กล่อง+ลูกศรลำดับ 1–5 และกล่องคำอธิบายสัญลักษณ์ |

ทั้ง 3 ไฟล์เขียนภายใต้กฎข้อ 2 ทุกข้อ (ไม่มี `style`, ไม่มี backslash, ไม่มี `url()`, ฟอนต์ระบบ, stroke 2px, viewBox 800×450)
**[UNVERIFIED]** ยังไม่ได้รันผ่าน `sanitizeSvg()` จริง (สภาพแวดล้อมของ ui-designer รันสคริปต์ไม่ได้) —
`frontend-dev` ควรเพิ่มไฟล์ทั้ง 3 เป็น fixture ใน `web/src/lib/svgSanitizer.test.ts` ให้ผลเป็น `ok: true` และ `warnings.length === 0`

## 8. วิธีแสดงผลใน UI (ผูกกับ `IllustrationFrame`)

- กรอบ `aspect-video bg-surface-2 rounded-md border border-line`, SVG scale ตาม viewBox
- ป้าย "ภาพประกอบโดย AI — เชิงแผนผัง" มองเห็นตลอดเวลา (มุมล่างซ้าย) — ห้ามซ่อน
- caption ใต้ภาพ + ปุ่ม "สร้างภาพใหม่" / "ซ่อนภาพ"; lightbox ขยายเต็มจอ
- ถ้า sanitizer ตัดอะไรออก → แสดง FlagBadge + รายการที่ถูกตัด (โปร่งใส ไม่ซ่อน)
- ใน PDF: แปลงเป็น PNG ก่อนฝัง (spike S5) — ข้อความในภาพจะกลายเป็นภาพ จึงต้องมี caption ข้อความจริงกำกับเสมอ
