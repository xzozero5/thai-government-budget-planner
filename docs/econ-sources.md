## รายละเอียดต่อ indicator

### `gdp_growth_pct`, `usd_thb_avg`, `inflation_pct`, `cpi_headline_index`

- **แหล่งที่ใช้จริง**: World Bank Open Data API (`api.worldbank.org`) — ดึงด้วย `curl` ตรงและอ่าน JSON response จริงในเครื่องมือ Bash ของ session นี้ (ไม่ใช่ WebFetch summarization) จึงมั่นใจว่าเลขไม่ได้ถูกสรุปผิดโดยโมเดลตัวช่วย
  - GDP growth: `NY.GDP.MKTP.KD.ZG` → `https://api.worldbank.org/v2/country/THA/indicator/NY.GDP.MKTP.KD.ZG?format=json&date=2014:2026&per_page=50`
  - Exchange rate: `PA.NUS.FCRF` (period average, LCU per US$) → `https://api.worldbank.org/v2/country/THA/indicator/PA.NUS.FCRF?format=json&date=2014:2026&per_page=50`
  - Inflation: `FP.CPI.TOTL.ZG` → `https://api.worldbank.org/v2/country/THA/indicator/FP.CPI.TOTL.ZG?format=json&date=2014:2026&per_page=50`
  - CPI index: `FP.CPI.TOTL` (2010=100) → `https://api.worldbank.org/v2/country/THA/indicator/FP.CPI.TOTL?format=json&date=2014:2026&per_page=50`
- **base year**: CPI index ของ World Bank ใช้ปีฐาน **2010=100** — ต่างจากปีฐานทางการของไทย (สนค. TPSO ใช้ 2562=100 ปัจจุบัน, ก่อนหน้าใช้ 2558=100) → มี `base_year_differs` note ทุก record ห้ามนำ index ชุดนี้ไปต่อ/เทียบกับ index ที่ publish จาก TPSO โดยตรงในอนาคต
- **ข้อจำกัด/คุณภาพข้อมูล**:
  - เป็น **secondary_source** ทั้งหมด — ไม่ใช่ตัวเลขทางการที่ สนค./ธปท./สศช. เผยแพร่เอง
  - `inflation_pct` ปี 2567 จาก World Bank = 0.40% แต่บทวิเคราะห์ สนค. (fetch ได้จริงจาก `https://www.price.moc.go.th/price/fileuploader/file_cpi/Cpi_tg.pdf`) รายงานเงินเฟ้อเฉลี่ย 7 เดือนแรกปี 2567 (ม.ค.–ก.ค., AoA) = 0.11% และ YoY เดือน ก.ค. 2567 = 0.83% — ตัวเลขไม่ตรงกันเพราะวิธีคำนวณเฉลี่ยรายปีต่างกัน (ยังไม่ยืนยันวิธีคำนวณที่ World Bank ใช้แน่ชัด) — **ต้องระวังเวลาใช้เทียบกับตัวเลขที่ สนค. แถลง**
  - ปี 2569 (2026) เป็น null ทุกตัว — ปีงบ/ปีปฏิทินยังไม่จบ ไม่มีข้อมูลเต็มปี
- **แหล่งทางการที่ลองแล้วแต่ fetch ไม่ได้**:
  - `index.tpso.go.th` — เป็น Next.js SPA, HTML ที่ได้มีแต่ script bundle ไม่มี URL API ฝังตรง ๆ ที่ดึงต่อได้ในเวลาจำกัด
  - `tpso.go.th/economic-data/consumer-price-index`, `.../construction-materials-price-index` — เป็นหน้ารวมลิงก์ ไม่มีตัวเลข
  - `bot.or.th/th/statistics/exchange-rate.html`, `app.bot.or.th/BTWS_STAT/...` — dynamic report ต้องเลือกพารามิเตอร์ผ่าน JS/ฟอร์ม
  - `nesdc.go.th` — มีเฉพาะรายงานรายไตรมาสแบบ PDF/PPT รายฉบับ ไม่มีตารางสรุปรายปีที่ fetch ได้ในเวลาที่กำหนด
  - `bot.or.th/content/dam/bot/documents/th/statistics/attachment-files/indicators.pdf` — fetch ได้ (2.9MB) แต่เป็นตารางตัวเลขในรูปแบบที่ WebFetch tool อ่านไม่ออก (ไม่ลอง parse ด้วย pypdf ต่อเนื่องจากเวลาจำกัด)
- **วิธีอัปเดตปีถัดไป**: เรียก World Bank API เดิมด้วย `date` range ใหม่ (จะได้ค่าปีก่อนหน้าปรับปรุงด้วยถ้ามี revision); พยายาม reverse-engineer network call ของ `index.tpso.go.th` (devtools) เพื่อดึงข้อมูลทางการโดยตรงในรอบถัดไป

### `government_budget_total_mthb` — coverage เต็ม 12/12 ปี

- **แหล่ง**: หน้าวิกิพีเดีย "งบประมาณแผ่นดินของไทย" (`https://th.wikipedia.org/wiki/งบประมาณแผ่นดินของไทย`) — fetch เนื้อหา HTML จริงด้วย curl แล้วอ่านตารางที่พบ (มี reference อ้างอิง **ราชกิจจานุเบกษา** พ.ร.บ.งบประมาณรายจ่ายประจำปีแต่ละฉบับต่อท้ายทุกแถว) → ระบุ `secondary_source` เพราะเป็นวิกิพีเดีย แต่เนื้อหาต้นทางที่อ้างอิงคือกฎหมายจริง
- **cross-check ปี 2569**: ยืนยันตรงกันกับเอกสาร "วิเคราะห์ร่างพระราชบัญญัติงบประมาณรายจ่ายประจำปีงบประมาณ พ.ศ. 2569" โดย **สำนักงบประมาณของรัฐสภา (PBO)** — fetch PDF จริง (`https://web.parliament.go.th/assets/portals/82/news/1597/1_1597.pdf`, หน้า 5 ของเอกสาร) ข้อความ: *"วงเงินงบประมาณรายจ่ายประจำปีงบประมาณ พ.ศ. 2569 ได้กำหนดกรอบวงเงินงบประมาณจำนวน 3,780,600 ล้านบาท"* — ตรงกับตัวเลขในวิกิพีเดีย 100%
- **ตัวเลข** (ล้านบาท, ไม่รวมงบประมาณรายจ่ายเพิ่มเติมเว้นแต่ระบุ): 2558=2,575,000 · 2559=2,720,000 (+เพิ่มเติม 56,000) · 2560=2,733,000 (+190,000) · 2561=2,900,000 (+150,000) · 2562=3,000,000 · 2563=3,200,000 · 2564=3,285,962 (ละเอียด 3,285,962.4797) · 2565=3,100,000 · 2566=3,185,000 · 2567=3,480,000 (+122,000) · 2568=3,752,700 · 2569=3,780,600
- **ข้อจำกัด**: ไม่รวมงบประมาณรายจ่ายเพิ่มเติมกลางปี (มีแยกในวงเล็บบางปี) — ถ้าจะใช้ "วงเงินรวมทั้งปีจริง" ต้องบวกเพิ่มเติมเอง (ยังไม่ทำ เพื่อไม่ปนกับตัวเลข พ.ร.บ. หลัก)
- **วิธีอัปเดตปีถัดไป**: หลัง พ.ร.บ.งบประมาณปีใหม่ประกาศในราชกิจจานุเบกษา → ตรวจ `bb.go.th/topic3.php?gid=862&mid=545` (ฉบับ พ.ร.บ.) โดยตรงแทนวิกิพีเดียถ้าเป็นไปได้

### `min_wage_bangkok_thb` — มีเฉพาะปี 2568

- **แหล่ง**: หน้าวิกิพีเดีย "ค่าจ้างขั้นต่ำในประเทศไทย" (`https://th.wikipedia.org/wiki/ค่าจ้างขั้นต่ำในประเทศไทย`) — fetch จริง พบตารางค่าจ้างขั้นต่ำตามประกาศคณะกรรมการค่าจ้าง **ฉบับที่ 13** มีผลตั้งแต่ 1 มกราคม 2568: กรุงเทพมหานคร/นครปฐม/นนทบุรี/ปทุมธานี/สมุทรปราการ/สมุทรสาคร = **372 บาท/วัน**
- **ข้อควรระวัง (ยังไม่ยืนยัน)**: มีข่าว (ยังไม่ fetch ต้นฉบับ) ว่า ครม. เห็นชอบอัตรา 400 บาท/วัน สำหรับพื้นที่ กทม. เฉพาะกิจการโรงแรม/สถานบริการ มีผล 1 ก.ค. 2568 — เป็นอัตรา**เฉพาะกลุ่มอาชีพ** ไม่ใช่อัตราทั่วไปของพื้นที่ จึง**ไม่ได้แทนที่ 372** ในไฟล์นี้ ต้องตรวจสอบราชกิจจานุเบกษาฉบับจริงก่อนตัดสินใจว่าจะปรับค่าสิ้นปี 2568 เป็นเท่าไหร่ (กฎ N3 ข้อค่าจ้างขั้นต่ำ: "เก็บค่าที่มีผล ณ สิ้นปีปฏิทิน" — ถ้าอัตรา 400 มีผลจริงและครอบคลุมพื้นที่ทั่วไป ต้องแก้เป็น 400 พร้อม note วันที่มีผล)
- **ปีอื่น (2558–2567, 2569) = null** — ลองแหล่งต่อไปนี้แล้วไม่สำเร็จ:
  - กระทรวงแรงงาน (mol.go.th) — ไม่พบหน้าตารางย้อนหลังที่ fetch ได้ในเวลาจำกัด
  - วิกิพีเดียหน้าเดียวกัน — มีเฉพาะตารางฉบับล่าสุด (ฉบับที่ 13) ไม่มีตารางฉบับก่อนหน้าเต็มรูปแบบ (ฉบับที่ 9, 12 ฯลฯ ถูกอ้างถึงแต่ไม่มีตัวเลขในเนื้อหา)
  - `km.fti.or.th` (สภาอุตสาหกรรมฯ) — ลิงก์จาก search ไม่ได้ชี้ไปเนื้อหาประกาศจริง (ไปหน้าเมนูรวมแทน)
  - `library.parliament.go.th/th/radioscript/xatrakhacangkhanta` — ตอบ 403 Forbidden
  - `khaosod.co.th` บทความ "20 ปี แรงงานไทย ค่าแรงขั้นต่ำเท่าไหร่" — ติด Cloudflare challenge (JS verification) fetch ไม่ผ่าน
- **วิธีอัปเดต/เติมข้อมูลย้อนหลัง**: ค้นหาประกาศคณะกรรมการค่าจ้างแต่ละฉบับ (ฉบับที่ 8–14) ในราชกิจจานุเบกษาโดยตรง (ratchakitcha.soc.go.th) — ต้องระวังว่าอาจเป็น PDF สแกนไม่มี text layer (N4 ห้าม OCR)

### `construction_material_index` และ `cmi_*` — null ทั้งหมด, มี mapping issue สำคัญ

- **สิ่งที่ fetch เห็นจริง**: รายงานรายเดือน (bulletin PDF) ของ สนค. ที่ `https://www.price.moc.go.th/price/fileuploader/file_csi/Csi.pdf` — ฉบับเดือนพฤศจิกายน 2567 (เผยแพร่ 4 ธ.ค. 2567) มีตารางดัชนีราคาวัสดุก่อสร้างแยก 9 หมวด (ปีฐาน **2558=100**, ครอบคลุม 12 จังหวัด, 136 รายการสินค้า):

  | หมวด TPSO | น้ำหนัก | ดัชนี พ.ย. 2567 |
  |---|---|---|
  | ไม้และผลิตภัณฑ์ไม้ | 5.28% | 138.2 |
  | ซีเมนต์ | 11.33% | 99.1 |
  | ผลิตภัณฑ์คอนกรีต | 16.77% | 112.2 |
  | เหล็กและผลิตภัณฑ์เหล็ก | 28.45% | 130.4 |
  | กระเบื้อง | 7.33% | 108.9 |
  | วัสดุฉาบผิว | 3.23% | 108.5 |
  | สุขภัณฑ์ | 2.05% | 96.2 |
  | **อุปกรณ์ไฟฟ้าและประปา** (รวมกัน) | 12.72% | 108.0 |
  | วัสดุก่อสร้างอื่น ๆ (รวมยางมะตอย) | 12.83% | 105.8 |

  ตัวเลขนี้เป็น **รายเดือนเดียว ไม่ใช่ค่าเฉลี่ยรายปี** — ตาม N3 การจะได้ annual average ต้อง fetch ครบ 12 เดือน + note `derived: mean of 12 monthly values` พร้อม URL รายเดือนทั้งหมด ซึ่งเกินเวลาที่จัดสรรไว้ในรอบนี้ (ต้อง fetch เอกสารแยกไฟล์ต่อเดือนต่อปี × 11 ปี × ~9 หมวด) จึงตัดสินใจเก็บเป็น `null` แทนการเดา
- **mapping issue สำคัญที่ต้องรายงาน PO/architect**: indicator ที่ spec ขอ (`cmi_electrical`, `cmi_plumbing`, `cmi_asphalt_petroleum`) **ไม่ตรงกับหมวดจริงที่ สนค. เผยแพร่**:
  - `cmi_electrical` และ `cmi_plumbing` — สนค. เผยแพร่เป็นหมวดรวมเดียว **"อุปกรณ์ไฟฟ้าและประปา"** ไม่ได้แยกไฟฟ้ากับประปาเป็นดัชนีคนละตัว จึงไม่มีทางได้ค่าที่ตรงตาม field name ทั้งสองนี้แยกกันจากแหล่งทางการ (นอกจากขอข้อมูลดิบจาก สนค. โดยตรง)
  - `cmi_asphalt_petroleum` — ไม่มีหมวดนี้เป็นเอกเทศ ยางมะตอยเป็นสินค้าหนึ่ง (1 รายการ) ที่ถูกรวมอยู่ใน **"หมวดวัสดุก่อสร้างอื่น ๆ"** ร่วมกับสินค้าอื่น (เช่น หน้าต่าง UPVC) — ดัชนีหมวดนี้จึงไม่ใช่ตัวแทนราคายางมะตอย/ปิโตรเลียมล้วน ๆ
  - **ข้อเสนอ**: ทีม PO/architect ควรพิจารณาปรับ spec ให้ `cmi_electrical_plumbing` (รวม) แทน 2 ตัวแยก และตัด/เปลี่ยนนิยาม `cmi_asphalt_petroleum` เป็นราคาน้ำมัน/ยางมะตอยจากแหล่งอื่น (เช่น EPPO) แทนการหาใน CMI ของ สนค.

## ข้อสังเกตคุณภาพข้อมูลรวม (สำหรับคนตรวจ)

1. **สัดส่วนความครอบคลุมโดยรวมต่ำ (~24% ของ 195 cell)** — ส่วนใหญ่เพราะเว็บราชการไทยที่เกี่ยวข้อง (TPSO/BOT/NESDC/EPPO) เป็น JavaScript SPA หรือ dynamic report ที่ WebFetch/curl ธรรมดาดึงตัวเลขจริงไม่ได้ในเวลาที่จัดสรร — indicator ที่ครอบคลุมเต็ม (`government_budget_total_mthb`) สำเร็จเพราะมีแหล่งทุติยภูมิ (วิกิพีเดีย) ที่รวบรวมข้อมูลจากราชกิจจานุเบกษาไว้เป็นตารางสำเร็จรูปแล้ว
2. `inflation_pct`/`cpi_headline_index` จาก World Bank **ไม่ควรใช้แทนตัวเลขทางการ สนค.** โดยตรงในหน้า UI ถ้าจะโชว์ "อัตราเงินเฟ้อทางการ" — ควรมีป้ายกำกับแหล่งชัดเจนหรือรอจนกว่าจะดึงจาก TPSO ได้จริง
3. `cmi_*` มี structural mismatch ระหว่าง spec กับข้อมูลจริงของ สนค. (ดูหัวข้อด้านบน) — ควรแก้ spec ก่อนพยายามหาข้อมูลเพิ่มรอบหน้า ไม่งั้นจะเสียเวลาหาสิ่งที่ไม่มีอยู่จริง
4. ทุก record ที่ `value` เป็น `null` มี `note` อธิบายแหล่งที่ลองแล้วโดยละเอียด เพื่อให้รอบถัดไปไม่ต้องเริ่มค้นใหม่จากศูนย์
