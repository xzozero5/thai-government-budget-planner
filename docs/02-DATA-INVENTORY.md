ข้อสรุป: **PDF ส่วนใหญ่เป็นภาพสแกน** → ตาม scope ไม่ OCR แต่ pipeline ต้อง:
1. สแกนทุก PDF (261 ไฟล์) ด้วย `pdfinfo` + `pdftotext -l 3` → บันทึก `has_text_layer`, `pages`, `size` ลง `sources.json`
2. PDF ที่มี text layer → extract เป็น text chunks ต่อหน้า (สำหรับ RAG แบบ keyword) และตาราง (pdfplumber) ถ้าตรวจพบ
3. PDF ที่ไม่มี → เก็บเฉพาะ metadata + path + ชื่อเรื่อง/หน่วยงาน/วันที่ที่ parse จากชื่อโฟลเดอร์ ให้ AI "รู้ว่ามีเอกสารนี้" และบอกผู้ใช้ให้ไปเปิดเอง

ไฟล์ใหญ่ที่ควรข้ามการอ่านเนื้อหาแม้จะมี text (ให้เก็บ metadata อย่างเดียว ถ้า > 100 MB): `สัญญา TH-AI Passport` 98.9 MB, `_เลือกตั้ง ผอ.` 63 MB, ข้อบัญญัติ 5 ไฟล์ 100–260 MB

## C. โครงสร้างโฟลเดอร์ → metadata

- `กมธ.ติดตามงบ/ครั้งที่ N (วัน เดือน ปี)/<เรื่อง>/<หน่วยงาน>/ไฟล์` → parse `meeting_no`, `meeting_date` (พ.ศ.), `topic`, `agency`
  ระวัง: ชื่อโฟลเดอร์มี **zero-width space (U+200B)** เช่น `ครั้งที่​ 10` — ต้อง normalize unicode ก่อน regex
- `งบประมาณ <จังหวัด>/<ลำดับ> - <ระดับ>/ไฟล์` → `province`, `level` (ฟังก์ชัน/อบจ./เทศบาล/อบต.)
- `OPEN SSO/` → `agency = สำนักงานประกันสังคม`, ปีจากชื่อไฟล์
