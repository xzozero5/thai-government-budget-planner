# ADR-004 — PBO ปี 2562: ไฟล์ต้นทางไม่ครบ → เก็บไว้พร้อมป้าย ไม่ทิ้ง

- **Status**: Accepted — 2569-09-19 (main thread) · แจ้งคุณนิวในสรุป Phase 1 (ถ้ามีไฟล์ 2562 ฉบับครบ ให้นำมาแทนแล้วรัน pipeline ใหม่)
- **Links**: 02 §A1, 03 §6 (V1), `pipeline/data/known_source_gaps.yaml`, T-105, T-110, 05 (tool `query_budget_lines` / system prompt)

## Context (ยืนยันแล้วจากไฟล์จริง)
`PBO/2562.xlsx` แถว Grand Total ระบุ พรบ. = 3,000,000 ล้านบาท แต่ผลรวมแถวข้อมูลจริง ≈ 2,377,340 ล้านบาท (≈ 79 %). main thread query cache เทียบปี 2561/2563 พบว่า **ไม่มีแถวของทั้งกระทรวง**: การคลัง, กลาโหม, การต่างประเทศ, การพัฒนาสังคมฯ, การท่องเที่ยวและกีฬา, รายจ่ายเพื่อชดใช้เงินคงคลัง และมีเพียงบางส่วนของ เกษตรและสหกรณ์ (≈ 23,443 เทียบ ≈ 122,573 ปี 2561) กับ สำนักนายกรัฐมนตรี (≈ 2,414 เทียบ ≈ 33,875). นอกจากนี้แถว Excel 226–227 คอลัมน์เลื่อน (ค่า พรบ. 6.07×10¹¹ ล้านบาท — เป็นไปไม่ได้). ปีอื่นที่มี oracle ผลรวมตรงระดับ < 0.01 %.
สาเหตุที่ไฟล์ไม่ครบ: **ไม่ทราบ** `[UNVERIFIED]` (อาจเป็นการ export ไม่ครบจากต้นทาง) — ห้ามเดาในเอกสาร/ UI

## Options
1. ทิ้งปี 2562 ทั้งปี — เสียข้อมูล 217k แถวที่ถูกต้องในตัวเอง (ศึกษาธิการ, มหาดไทย, คมนาคม ฯลฯ ครบ) และทำให้ trend ขาดช่วง
2. เก็บโดยไม่บอก — ผิดหลัก evidence-first: ผู้ใช้/AI อาจสรุปว่า "ปี 2562 กลาโหมไม่มีรายการนี้"
3. **เก็บ + ประกาศช่องว่างแบบ machine-readable** ✔

## Decision
- เก็บแถวปี 2562 ทั้งหมด; แถวคอลัมน์เลื่อน → ฟิลด์เงินเป็น null + flag `corrupt_row` (กฎทั่วไป: ข้อความในคอลัมน์เงิน หรือ |ค่า| > 10 ล้านล้านบาท)
- `known_source_gaps.yaml` บันทึก coverage %, กระทรวงที่หาย/ไม่ครบ; V1 ของปีนี้ได้สถานะ **`source_incomplete`** (ไม่ใช่ pass, ไม่ทำให้ build ล้ม, แต่ถ้า coverage เปลี่ยนจากที่บันทึก → fail)
- T-110 ใส่ `coverage_notes` ลง `manifest.json` + `catalog/facets.json`; Phase 3: tool result ของปี/กระทรวงที่เกี่ยวต้องแนบ note นี้ และ system prompt ห้ามตีความ "ไม่พบใน 2562" ว่า "ไม่มีงบ"; Phase 4: citation drawer/ trend chart แสดงป้าย "ข้อมูลปี 2562 ไม่ครบ"
- trend ราคาต่อหน่วย (median ต่อ item_key) ยังใช้ปี 2562 ได้ เพราะเป็นสถิติระดับรายการ ไม่ใช่ยอดรวม

## Consequences
- V1 มี 4 สถานะ: `pass` / `fail` / `no_oracle` (2567) / `source_incomplete` (2562)
- เพิ่ม check ทั่วไป "กระทรวงหายทั้งก้อนเทียบปีข้างเคียง" (soft) เพื่อจับ gap แบบเดียวกันในปีที่ไม่มี oracle
- ไม่เข้า `[ASK-HUMAN]` ข้อ 2 (ไม่ได้เลือกทิ้งข้อมูล) แต่ต้องรายงานคุณนิว
